# xdp-tutorial
Each directory inside contains README to run that specific code.

The repo contains various eBPF networking related codes: basic XDP Dump, XDP Dump with gRPC, TC/eBPF to capture egress packets, using tc/eBPF to capture inner destination packets of openconnect clients, eBPFShield. 

1. [eBPFShield](https://github.com/NobinPegasus/xdp-tutorial/tree/nobin/eBPFShield)
2. [Open Connect Packet Capture](https://github.com/NobinPegasus/xdp-tutorial/tree/nobin/openconnect_packet_capture)
3. [TC/eBPF with blacklist filter](https://github.com/NobinPegasus/xdp-tutorial/tree/nobin/tc-ebpf-with-blacklist-filter)
4. [XDP Dump](https://github.com/NobinPegasus/xdp-tutorial/tree/nobin/xdp-tutorial/xdp_dump)
